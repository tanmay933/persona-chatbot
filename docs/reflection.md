# Reflection

This project helped me understand how critical prompt engineering is when building AI applications. Initially, my prompts were generic, and the responses felt similar across all personas. This clearly demonstrated the principle of "Garbage In, Garbage Out" — weak prompts lead to weak outputs.

After refining the system prompts with better persona descriptions, structured few-shot examples, and clear constraints, the difference in responses became noticeable. Each persona started behaving more distinctly, which improved the realism of the chatbot.

One key takeaway was the importance of specificity. Defining tone, response style, and behavioral boundaries made the model far more predictable and aligned with expectations.

Another important learning was system design thinking — separating frontend, API logic, and prompt layers made the application easier to manage and extend.

If I had more time, I would further improve:
- UI/UX with better styling and animations
- Add memory to conversations
- Make prompts even more aligned with real-world data

Overall, this project gave me a practical understanding of how prompt design directly impacts product quality.
